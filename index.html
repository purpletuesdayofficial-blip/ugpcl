UGPCL

Universal General Purpose Configuration Language

A minimal interpreted configuration and scripting language built around sections, modules, and deterministic execution.

What is this?

UGPCL is a lightweight language designed for structured execution and modular expansion via UGPCI and UGPIP.

Core Idea

- Section-based execution model
- Minimal syntax
- External module system (UGPIP)
- GitHub-based package imports

Example

1'2

1,1:import,extra
2,1:print,str,Hello World
!;

Modules

extra → printing and runtime helpers
graphic → terminal control and colors
debug → state inspection tools

How it runs

python ugpci/main.py file.ugcpl

Status

Early alpha. Actively evolving interpreter + module system.
